NB 3 Wireless and Mobile Networks

Created in February 21, 2026

2026   ·   networks

  • Topics
    • Wireless Networks
    • Mobile Device Connectivity
A. Wireless Networks
  1. Types of Wireless Networks
    • Phones communicate on many different networks:
      • Voice channel → Cellular provider network
      • Using a Bluetooth device → Bluetooth
      • Communicating over the global internet → Wi-Fi
      • Sending information over extremely short distances (e.g., paying using phones) → Near Field Communication (NFC)
    • Phones are also capable of receiving GPS signals
      • Receiving signals from satellites around the Earth
      • Satellites send signals to devices with GPS capability
  2. Cell Phone Interactions with Different Networks
    • Talk
      • Communicate with landlines, cell phones, and businesses
      • Cell phones contain multiple receivers and transmitters
    • Data
      • Uses a data plan
      • Enables internet access when not near Wi-Fi
      • Uses cellular infrastructure to access the internet
    • Wi-Fi
      • Connects to hotspots and home wireless networks
    • Location Services
      • GPS, maps, and location-based services
    • Pay Services
      • Cash registers, payment pads
      • Uses NFC
  3. Other Wireless Networks
    • Smartphones connect in several ways besides cellular networks

Global Positioning System (GPS)

  • Uses satellites to transmit signals covering the Earth
  • Phones calculate their location within about 10 meters accuracy

Wi-Fi

  • Allows phones to connect to local networks and the internet
  • Requires being within range of a wireless access point

Bluetooth

  • A low-power, short-range wireless technology
  • Replaces wired connections for accessories such as:
    • Speakers
    • Headphones
    • Microphones
    • Smartwatches
  • Can transmit both voice and data
  • Enables multiple devices to communicate simultaneously

Near Field Communication (NFC)

  • Uses electromagnetic fields to transmit data
  • Allows data exchange when devices are very close together (usually a few centimeters)
  • Example: smartphone payment systems
B. Mobile Device Connectivity
  1. Mobile Devices and Wi-Fi
    • Mobile devices allow users to:
      • Work
      • Learn
      • Play
      • Communicate from anywhere
    • Tasks previously requiring large computers can now be completed using mobile devices on wireless networks
    • It is advisable to connect to Wi-Fi instead of cellular data when possible because:
      • Wi-Fi uses less power
      • Helps conserve battery life
    • Security precautions when using Wi-Fi
      • Never send login or password information using plaintext
      • Use a VPN when sending sensitive data
      • Enable security on home networks
      • Use WPA2 or higher encryption
  2. Wi-Fi Settings
    • Two popular mobile operating systems:
      • Android
      • Apple iOS
    • Both provide settings to configure connections to wireless networks
  3. Configure Mobile Wi-Fi Connectivity
    • If a device does not prompt to connect to Wi-Fi:
      • The SSID broadcast may be disabled
      • The device may not be set to connect automatically
    • SSID
      • The name assigned to a wireless network
    • Passphrase
      • The wireless network password
    • SSIDs and passphrases must be typed exactly as configured on the router.
  4. Configure Cellular Data Settings
    • Cellular data plans are provided by mobile carriers
    • Bandwidth and usage costs vary by carrier and plan
    • Mobile devices are typically configured to:
      • Use Wi-Fi first
      • Switch to cellular data when Wi-Fi is unavailable
    • Network transitions are usually automatic:
      • Example: switching from 4G to 3G coverage
      • Connections are typically not interrupted
  5. Simple Connectivity with Bluetooth
    • Devices connect using different methods:
      • Cellular
      • Wi-Fi
      • Wired connections
    • Bluetooth advantages
      • Wireless
      • Automatic
      • Low power consumption
    • Up to eight Bluetooth devices can be connected at the same time.
  6. Bluetooth Pairing
    • Bluetooth pairing occurs when two devices establish a connection to share resources.

Pairing process

  1. Turn on Bluetooth radios
  2. One device searches for other devices
  3. Other devices must be set to discoverable (visible) mode

When discoverable, devices transmit:

  • Device name
  • Bluetooth class
  • Supported services
  • Technical specifications

During pairing:

  • A PIN or passkey may be required
  • The PIN is stored so future connections occur automatically
Summary
  1. Wireless Networks
    • Mobile phones use radio waves to transmit voice signals to cell towers.
    • When a call is made:
      • The signal is relayed between towers until it reaches its destination.
    • Wireless networks are used for:
      • Voice calls
      • Text messages
      • Data transmission
    • The most common cellular network type is GSM.
    • 3G, 4G, 4G-LTE, and 5G
      • Represent enhanced cellular networks optimized for faster data transmission
    • Wi-Fi
      • Allows smartphones to connect to local networks and the internet
      • Often available through public hotspots
    • Bluetooth
      • Enables communication between devices over short distances
    • NFC
      • Allows devices to exchange data at very close range
  2. Mobile Device Connectivity
    • To protect Wi-Fi communications:
      • Never send login credentials in plaintext
      • Use VPNs when sending sensitive data
      • Secure home networks
      • Use WPA2 or stronger encryption
    • Mobile devices:
      • Prefer Wi-Fi when available
      • Use cellular data when Wi-Fi is unavailable
    • Bluetooth technology
      • Enables easy connections between devices and accessories
      • Uses minimal power
    • Bluetooth pairing
    • Requires:
      • Bluetooth enabled
      • Device discovery
      • Discoverable mode
    • A PIN may be required during pairing for authentication.
Questions
  • What are GSM transmitters and receivers?
    • Global System for Mobile Communications (GSM) transmitters and receivers are radio components used in mobile phones and cellular towers to send and receive voice and data signals over cellular networks
    • A transmitter
      • sends radio signals from a mobile device to a nearby cell tower (base station)
    • A receiver
      • receives radio signals from the tower back to the mobile device
    • In a GSM network,
      1. A phone transmits a signal (a voice, text, or data) to the nearest cell tower
      2. The tower receives the signal and forwards it throught the carrier’s network
      3. The signal is routed to another tower near the destination.
      4. That tower trransmits the signal to the receiving phone.
    • These transmitters and receivers allow phones to communicate wirelessly using radio frequencies instead of physical cables


  • What is the difference between 3G, 4G, 5G, and Wi-Fi?
    • the main difference is how the network is provided and how devices connect to it.
Technology Type Main Use Key Feature
3G Cellular network Mobile internet and calls Early mobile data
4G/4G-LTE Cellular network Faster mobile internet supports streaming, video calls, and apps
5G Cellular network Very high-speed mobile internet Lower latency and much faster speeds
Wi-Fi Local wireless network Internet access in homes,, offices, and hotspots Uses a router instead of cellular towers


  • Is the statement “Up to eight Bluetooth devices can be connected together at any one time” still accurate?
    • Yes, but it depends on the Bluetooth setup
    • Classic Bluetooth (piconet)
      • one master device
      • up to 7 connected devices
      • common for headphones, speakers, keyboards, mice
    • Bluetoot Low Energy (BLE)
      • can support many more devices, depending on the hardware and software implementation
      • used in modern devices like smartwatces, IoT devices, and sensors
Reflection

Wireless and mobile networks allow devices to send and receive data without physical cables, enabling communication, internet access, and device interaction through wireless technologies.
