##### <mark style="background-color: #87CEEB;">A. Clients and Servers </mark>

* Computer hosts can act as:
  - Client
  - Server
  - Both
* The role of a device depends on the **software installed**.
* Servers
  - Provide information or services to other hosts
  - Examples: email servers, web servers
* Clients
  - Request and display information from servers
  - Example: web browsers like Chrome
* Example interactions
  - Client requests a webpage from a web server
  - Web server responds with the webpage
  - Email clients (Outlook) access email from email servers
  - Clients can send and receive emails through the server
* Service Types
  - Email
    - Runs email server software
    - Clients use mail client software like Outlook
  - Web
    - Runs web server software
    - Clients access through browsers like Chrome
  - File
    - Runs file server software
    - Stores files in a central location
    - Accessed through tools like Windows File Explorer

1. <u>Client and Server Roles</u>
* Hosts
  - Computers connected to a network
  - Participate directly in communication
  - Can send and receive messages
* Servers
  - Provide services to other hosts
  - Each service requires separate server software
  - Websites visited online are hosted on servers connected to the internet
* Clients
  - Request information from servers
  - Examples: Chrome, Safari

2. <u>Peer-to-Peer Networks</u>
* Client and server software usually run on separate computers
* However, one computer can run both
* In small businesses or homes:
  - Devices can act as both servers and clients
* Simplest P2P network
  - Two directly connected computers
  - Wired or wireless connection
  - Devices exchange data and services
* Advantages
  - Easy to set up
  - Less complex
  - Lower cost
  - Useful for file sharing and printer sharing
* Disadvantages
  - No centralized administration
  - Less secure
  - Not scalable
  - Performance can slow when devices act as both client and server

3. <u>Peer-to-Peer Applications</u>
* A P2P application allows a device to act as:
  - Client
  - Server
* Every client can also be a server
* Devices can:
  - Send messages
  - Receive messages simultaneously
* Hybrid P2P systems
  - Resource sharing is decentralized
  - Indexes are stored in a centralized directory
  - Peers query the index server to locate resources

4. <u>Multiple Roles in a Network</u>
* A computer with server software can serve multiple clients simultaneously
* One computer can run multiple server software
* One computer can also run multiple client software
* A host can connect to multiple servers at the same time
  - Example: checking email, browsing the web, instant messaging, streaming internet radio

##### <mark style="background-color: #87CEEB;">B. Network Components </mark>

1. <u>Network Infrastructure</u>
* Network paths can range from:
  - A single cable between two computers
  - A global network spanning the world
* Network infrastructure
  - The platform supporting network communication
  - Provides stable communication channels
* Three hardware categories
  - End devices
  - Intermediary devices
  - Network media
* Hardware examples
  - Laptop
  - Switch
  - Router
  - Access point
  - Network cables
* Some components are invisible
  - Wireless media using radio frequencies or infrared

1. <u>End Devices</u>
* Also called **hosts**
* Interface between users and the network
* Examples
  - Computers
  - Printers
  - Telephones
  - CCTV cameras
  - Mobile devices
* Can be:
  - Message source
  - Message destination
* Hosts are identified using **addresses**
* When communication starts
  - The sender uses the **destination address**

##### <mark style="background-color: #87CEEB;">C. ISP Connectivity Options </mark>

1. <u>ISP Services</u>
* Internet Service Provider (ISP)
  - Connects home networks to the internet
* Examples of ISPs
  - Cable providers
  - Telephone service providers
  - Cellular networks
  - Independent providers leasing bandwidth
* Additional services
  - Email accounts
  - Website hosting
  - Network storage
  - Backup and security services
* ISPs connect with other ISPs
  - Forming the global internet
* Internet backbone
  - High-speed fiber-optic infrastructure
  - Connects service provider networks worldwide

1. <u>ISP Connections</u>
* Internet backbone consists of
  - Fiber-optic cables
  - High-performance routers and switches
* Simple connection
  - Computer → Modem → ISP
  - Less secure
* Common connection
  - Computer → Router → ISP
  - Router provides:
    - Security
    - IP addressing
    - Wired and wireless connectivity

1. <u>Cable and DSL Connections</u>
* Most home users connect through:
  - Cable
  - DSL (Digital Subscriber Line)
* Cable
  - Uses coaxial cable from cable TV providers
  - High bandwidth
  - Always-on connection
* DSL
  - Uses telephone lines
  - Splits the line into channels:

    - Voice calls
    - Download data
    - Upload data
* Speed depends on
  - Line quality
  - Distance from the provider's central office

1. <u>Additional Connectivity Options</u>
* Cellular
  - Uses mobile networks
  - Available where cellular signal exists
  - Often metered
* Satellite
  - Useful where cable/DSL is unavailable
  - Requires clear line of sight
  - Higher installation costs
* Dial-up
  - Uses telephone line and modem
  - Low bandwidth
  - Mostly obsolete
* Fiber connections
  - Increasingly common in cities
  - Provide very high bandwidth
