## Penetration Testing Tools
A list of penetration tools with when to use them and some basic usage

| Tool | When to Use | Description | Basic Usage |
| :--  | :------------  | :------------ | 
| nmap  | Scanning | scans the target for open ports, OS and running versions, etc., which can be used for vulnerabilities | `nmap -O -sC -sV -A -p- [target site]` |
| GoBuster  | Web enumeration | brute-forces directories and files using wordlists | `gobuster dir -u [target site] -w [wordlist file]` |
| dirb  | Web enumeration | brute-forces directories and files using wordlists | `dirb [target site] -X [extensions]`|

## SOC Analyst Tools
A list of SOC technologies with descriptions, when to use, and some examples

| Tool | When to Use | Description | Examples |
| :--  | :------------  | :------------ | 
| Security Information and Event Management (SIEM) | Activity analysis | Analyzes activity from various resources and recognizes threats, can detect threats and investigate | Splunk, Microsoft Sentinel  |
| Security Information and Event Management (SIEM) | Data collection | An approach that uses data collection to detect and analyze cyber threats, monitors network traffic  | User and Entity Behaviour Analytics (UEBA), Network Traffic Analysis (NTA, like Wireshark) | 
| Firewall | For defense, Overseeing incoming and outgoing traffic | The first line of defense which decides whether to allow or block suspicious or insecure network traffic  | Cisco ASA, PaloAlto, Fortigate |
| Unified Threat Management (UTM) | For all-in-one defense | A single security solution that provides multiple features, such as antivirus, content filtering, and email and web filtering | Sophos UTM, Fortinet UTM, WatchGuard |

## Digital Forensics Tools
A list of penetration tools with when to use them and some basic usage

| Tool | When to Use | Description | Basic Usage |
| :--  | :------------  | :------------ | 
| Kroll Artifact Parser and Extractor (KAPE) | Incident response, forensic triaging | Used to rapidly collect and parse forensic artifacts (e.g., from live systems, disk images) for timeline analysis and incident investigations | `kape.exe --tsource [source] --tdest [dest]`; It is also a software |
| Forensics Toolkit (FTK) | During full digital forensic examination | A platform used for disk imaging, evidence indexing, file analysis, and for court investigations | Create a case → Add disk image → Analyze files, emails, and artifacts |
| Arsenal Image Mounter (AIM) | Forensic analysis of disk images | Used to mount forensic disk images (e.g. E01, RAW) as read-only, allowing investigators to analyzze evidence without altering the original image | Mount the image in read-only mode → Analyze using tools like FTK |
