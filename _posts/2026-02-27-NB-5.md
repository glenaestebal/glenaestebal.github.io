##### <mark style="background-color: #87CEEB;">A. Introduction </mark>

- Communication requires **rules or agreements** before it can happen.
- In networking, these rules are called **protocols**.
- Protocols ensure that communication between devices is successful.

* <u>Objectives</u>
  - Understand **communication protocols**
  - Understand **communication standards**
  - Compare **OSI and TCP/IP models**

---

##### <mark style="background-color: #87CEEB;">B. Communication Protocols </mark>

- Communication happens in different forms and environments.
- Each situation follows specific **rules and expectations**.
- Before communication:
  - The **method** must be defined
  - The **language** must be agreed upon
  - **Acknowledgement** may be required

* <u>Key Principles</u>
- Communication requires:
  - Identified sender and receiver
  - Agreed method of communication
  - Common language
  - Proper timing and speed
  - Confirmation or acknowledgement

---

1. <u>Why Protocols Matter</u>
- Computers rely on **protocols** to communicate.
- All devices in a network must use the **same protocol**.

* <u>Protocol Characteristics</u>
  - **Message Format**
    - Defines the structure of data being sent
  - **Message Size**
    - Data may be split into smaller pieces
  - **Timing**
    - Controls speed and data flow
  - **Encoding**
    - Converts data into signals (electrical, light, etc.)
  - **Encapsulation**
    - Adds addressing information to data
  - **Message Patterns**
    - Some communications require acknowledgements

---

##### <mark style="background-color: #87CEEB;">C. Communication Standards </mark>

1. <u>Devices in a Network</u>
- Devices only recognize their **own addressing information**.
- They rely on **protocols** to communicate with others.
- Data is broken into **packets** for transmission.
* <u>Examples of Protocol Roles</u>
- **Ethernet / WLAN**
  - Connect devices to the network
- **DHCP**
  - Assigns IP addresses
- **DNS**
  - Translates domain names to IP addresses
- **IP / TCP**
  - Ensures delivery of data

2. <u>The Internet and Standards</u>
- A **standard** is a set of rules for how something works.
- Standards ensure compatibility between devices.
- Different devices can communicate as long as they follow the same standards.

3. <u>Standards Organizations</u>
- Standards are developed and documented through **RFCs (Request for Comments)**.
- Managed by organizations like:
  - **IETF (Internet Engineering Task Force)**

---

##### <mark style="background-color: #87CEEB;">D. Network Communication Models </mark>

1. <u>The Protocol Stack</u>
- Communication uses multiple protocols working together.
- These protocols are organized into **layers**.
* <u>Example Layers</u>
  - **Application** – User-level communication
  - **Transport** – Reliable data delivery
  - **Internet** – Routing data
  - **Network Access** – Physical transmission

2. <u>The TCP/IP Model</u>
- A **layered model** used for internet communication.
- Helps visualize how protocols interact.
* <u>Layers</u>
- **Application**
  - Interface for user data
- **Transport**
  - Handles communication between devices
- **Internet**
  - Determines routing paths
- **Network Access**
  - Handles hardware and media
* <u>Benefits</u>
  - Simplifies design
  - Allows independent changes
  - Provides a common framework

3. <u>The OSI Model</u>
- A **reference model** used to understand networking.
- Does not define exact protocols, only functions.
* <u>Purpose</u>
  - Network design
  - Troubleshooting
  - Understanding communication processes
* <u>OSI Layers</u>
  - **7 – Application**
  - **6 – Presentation**
  - **5 – Session**
  - **4 – Transport**
  - **3 – Network**
  - **2 – Data Link**
  - **1 – Physical**

4. <u>OSI vs TCP/IP</u>
- Both models describe how networks function.
- TCP/IP is **practical and used in real networks**.
- OSI is **conceptual and used for learning**.
* <u>Mapping</u>
  - OSI Layers 5–7 → TCP/IP Application
  - OSI Layer 4 → TCP/IP Transport
  - OSI Layer 3 → TCP/IP Internet
  - OSI Layers 1–2 → TCP/IP Network Access

##### <mark style="background-color: #87CEEB;">Summary </mark>

* Communication Protocols
  - Rules that allow devices to communicate
  - Include format, timing, encoding, and delivery methods

* Communication Standards
  - Ensure compatibility between different devices
  - Allow global communication across networks

* Network Communication Models
  - Organize protocols into layers
  - **TCP/IP** is used in real-world networking
  - **OSI** helps in understanding and troubleshooting
