##### <mark style="background-color: #87CEEB;">A. Introduction </mark>

- A router connects a home network to the internet.
- Home routers typically have two main ports:
  - **Ethernet ports (LAN)**
  - **Internet ports (WAN)**
- Most home routers also include:
  - A radio antenna
  - A built-in wireless access point

---

##### <mark style="background-color: #87CEEB;">B. Home Network Basics </mark>

1. <u>Tyypical Home Network Setup</u>
- Most home networks include the following devices:
- **Modem**
  - Internet Access: Yes
  - Local Routing: No
  - Wi-Fi: No
  - Notes: Connects the home network to the ISP
- **Router**
  - Internet Access: No (needs modem)
  - Local Routing: Yes
  - Wi-Fi: No
  - Notes: Routes data between the modem and the local network
- **Access Point**
  - Internet Access: No (needs modem)
  - Local Routing: No
  - Wi-Fi: Yes
  - Notes: Adds wireless capability to a wired network
- **Wireless Router**
  - Internet Access: No (needs modem)
  - Local Routing: Yes
  - Wi-Fi: Yes
  - Notes: Combination of a router and an access point
- **Key Points**
  - Home networks usually consist of two networks:
  - **Public network** – Provided by the ISP.
  - **Private Ethernet network (LAN)** – Used by devices inside the home.
  - A **modem** converts the signal from the ISP into a format usable by the home network.
  - A **wireless router** connects devices within the LAN and provides internet access.

1. <u>Components of a Home Network</u>
- Devices commonly connected to a home network include:
  - Desktop computers
  - Gaming systems
  - Smart TVs
  - Printers
  - Scanners
  - Security cameras
  - Telephones
  - Smart home devices (e.g., climate control systems)

1. <u>Typical Home Network Routers</u>
- Home and small-business routers usually include two main port types:
- **Ethernet (LAN) Ports**
  - Connect to the internal switch of the router.
  - Used for wired devices.
  - All devices connected share the same local network.
- **Internet (WAN) Port**
  - Connects the router to another network (usually the modem).
  - Provides internet access to the LAN.
* Additional features:
  - Built-in wireless access point
  - Wireless and wired devices typically share the same LAN by default.

##### <mark style="background-color: #87CEEB;">C. Network Technologies in the Home </mark>

1. <u>LAN Wireless Frequencies</u>
- Most wireless home networks operate on:
  - **2.4 GHz band**
  - **5 GHz band**
- Example technologies:
- **Bluetooth**
  - Uses 2.4 GHz
  - Short-range, low-speed communication
- **Wi-Fi (IEEE 802.11 standards)**
  - Uses 2.4 GHz and 5 GHz bands

1. <u>Wired Network Technologies</u>
- Although wireless networking is common, wired connections are still useful for:
  - Faster speeds
  - Lower latency
  - More stable connections
- Ethernet Protocol
  - Most common wired networking protocol.
  - Uses Ethernet cables to connect devices in a LAN.
- Common Wired Media
- **Category 5e (Cat5e) Cable**
  - Unshielded twisted pair cable
  - Contains 4 twisted wire pairs
  - Used for Ethernet LANs
- **Coaxial Cable**
  - Single copper core with shielding
  - Commonly used for:
  - Cable internet
  - Television
  - CCTV systems
- **Fiber-Optic Cable**
  - Uses light to transmit data
  - Very high speed and bandwidth
  - Used for long-distance and high-speed internet connections

##### <mark style="background-color: #87CEEB;">D. Wireless Standards </mark>
* Wireless devices follow standards to ensure compatibility.
* The main organization responsible for these standards is the **IEEE (Institute of Electrical and Electronics Engineers).**

The **Wi-Fi Alliance**
: Tests wireless devices from different manufacturers to ensure compatibility.

1. <u>LAN Wireless Frequencies</u>
- Governed by the **IEEE 802.11 standard**
- Different amendments define various Wi-Fi technologies.
- Uses **2.4 GHz and 5 GHz bands**.

1. <u>Wireless Router Settings</u>
- Common wireless router settings include:
- **Network Mode**
  - Determines supported wireless technologies.
  - Examples: 802.11b, 802.11n, Mixed mode
- **Network Name (SSID)**
  - Identifies the wireless network.
  - All devices must use the same SSID to connect.
- **Standard Channel**
  - Defines the channel used for wireless communication.
- **SSID Broadcast**
  - Controls whether the network name is visible to nearby devices.
- **Important Notes**
- The SSID is:
  - Case-sensitive
  - Up to 32 characters long
  - included in wireless frames to identify the network.

##### <mark style="background-color: #87CEEB;">E. Setting Up a Home Router </mark>
* Many home routers include automatic setup utilities for initial configuration.

1. <u>First-Time Setup</u>
- To connect a router using a wired connection:
  - Connect an **Ethernet patch cable** to the computer.
  - Connect the other end to a **LAN port on the router**.
  - Do **not** connect to the Internet (WAN) port.
  - Verify the correct internet connection type.
- Examples:
- **Cable Internet**
  - Uses coaxial cable.
- **DSL Internet**
  - Uses a telephone cable (RJ-11).
- Most routers automatically assign an **IP address using DHCP**.
- If automatic configuration fails, manually configure:
  - IP address
  - Subnet mask
  - Default gateway
  - DNS server

1. <u>Network Design Considerations</u>
- **Choosing an SSID**
  - Visible to nearby devices if broadcasting is enabled
  - Avoid using: Router brand, Device Model
- **Device Compatibility**
  - Some devicees only support older Wi-Fi standards
  - Routers may need *legacy mode* enabled
  - Legacy mode supports: 802.11a, 802.11b, 802.11g, 802.11n, 802.11ac
  - However, enabling legacy mode may **reduce overall network speed**.
- **Guest Networks**
  - Some routers allow guest SSIDs.
  - Guests can access the internet but not local devices.

##### <mark style="background-color: #87CEEB;">Summary </mark>
* Home Network Basics
  - Home networks contain both **public and private networks**.
  - Devices connect to a router to share internet access and communicate locally.
* Network Technologies
  - Wireless networks use **electromagnetic waves**.
  - Most home wireless networks operate at **2.4 GHz or 5 GHz**.
  - Wired connections (Ethernet) offer stable and fast communication.
* Wireless Standards
- Managed by **IEEE 802.11**.
* Key router settings include:
  - Network Mode
  - SSID
  - Channel
  - SSID Broadcast
* Optimizing these settings ensures **secure and efficient wireless communication**.
